# St. Paul's Digital Twin — Visitor Controls & Navigation Manual

> **Scope:** Desktop keyboard, mouse look, inspection cameras, shortcuts, and accessibility controls.

---

## 1. Primary Desktop Walkthrough Controls

| Input Action | Primary Key / Interaction | Functionality |
|:---|:---|:---|
| **Walk Forward** | `W` or `Up Arrow` | Moves visitor forward in current gaze direction |
| **Walk Backward** | `S` or `Down Arrow` | Moves visitor backward |
| **Strafe Left** | `A` or `Left Arrow` | Moves visitor left perpendicularly |
| **Strafe Right** | `D` or `Right Arrow`| Moves visitor right perpendicularly |
| **Sprint** | `Shift` (Hold) | Increases walking pace from 4.0 m/s to 7.5 m/s |
| **Mouse Look** | **Left Click Canvas** | Engages pointer lock for seamless first-person mouse look |
| **Release Look** | `Escape` | Exits pointer lock, frees cursor for UI interaction |
| **Stair Climbing**| `Walk into Stair Flight` | Ascends/descends stairs smoothly onto floor landings |
| **Door Interaction** | `Approach (< 2.5m)` | Single-leaf doors pivot open smoothly, stay open, and close when clear |

---

## 2. Camera & Viewing Perspectives

Visitors can switch perspectives at any point:
- `1` or **1P Button:** **First-Person Walk** (Eye height 1.7m above floor level, realistic architectural viewpoint)
- `2` or **2P Button:** **Third-Person View** (Camera follows 3.5m behind visitor with avatar sightlines)
- `3` or **Orbit Button:** **Architectural Free Orbit** (Unconstrained architectural examination around buildings)

---

## 3. Keyboard Shortcuts & Command Palette

- `Cmd + K` or `/` : Open the **Destination Search** command palette. Filter by classrooms, labs, lecture halls, staff cabins, offices, or restrooms.
- `M` : Toggle **2D Architectural Floor Plan Viewer**. Click any room to calculate and preview a route. (Floor switching is preview-only and does not teleport the visitor).
- `X` : Toggle **3D Exploded / Stacked-Floor Mode**. Vertically separates floors to inspect alignment of courtyards, bridges, and stairs.
- `P` : Toggle **Curated Presentation Tour**. Automated camera showcase with presenter toolbar and waypoint stops.
- `R` : Safe Reset. Immediately returns visitor to the canonical starting position outside St. Paul's Main Entrance.
- `?` : Open on-screen Controls reference dialog.

---

## 4. Accessibility & Inclusive Features

Accessed via the Sliders icon in the top header:
1. **High Contrast Mode:** Switches to high-contrast monochrome backgrounds, bold cyan accents, and high-visibility route lines.
2. **Reduced Motion:** Replaces cinematic camera sweeps with calm crossfades and limits camera velocity.
3. **Large Typography:** Increases base font sizes for improved readability.
4. **Turn Direction Subtitles:** Displays clear textual turn-by-turn navigation captions.
5. **Simplified HUD:** Minimizes HUD card clutter for focused exploration.
